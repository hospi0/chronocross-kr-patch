# 말투 칸 한국어 설계 — 확정안 A + 안전장치 (2026-11-16)

## 1. 원작 구조 (요약)
- 범용 대사 1,002문장 = `{18:XX}`/`{15:XX}` 화자의 `{12:XX}` 칸 값을 끼워 찍음. 칸 21 × 인물 66 = 실행 파일 묶음 2~22 (TSV `cc_slot_*`)
- 칸 수·코드는 고정, **뜻은 우리가 정함**. 원작 사용 횟수: 일인칭 273 · のです 229 · だ 213 · 호칭 212 · 이인칭 156 · ない 127 · ん 110 · じゃ 89 · 부름말 87 · ぜ 67 · 1복수 67 · 2복수 64 · チッ 37 · か 31 · な 30 · 나머지 ≤15
- 호칭 `{08:81}`/`{08:82}` = 세르주 이름 앞 1·2글자 (애칭 처리 = 6장)

## 3. 번역 규칙 (범용 대사)
1. 칸 뒤 조사는 «는/를/와/로/도/의/만/한테/에게» 만(받침 없는 값 전제). «이/가» 주격은 12:12·12:11 사용
2. 종결은 2장 틀로만: «…ㄹ/ㄴ {12:02}.» «…ㄹ/ㄴ {12:04}?» «받침명사{12:01}» «무받침명사{12:08}» «해체어미{12:05}» «않{12:07}»
3. 틀 밖 종결(«-다», «-어»)은 화자 고정 대사에서만

## 4. 안전장치 (빌드 전 자동 검사 — `tools/slot_check.py`)
- 전수 렌더링: 범용 대사 × 동료 전원 → 화자별 읽기 파일 `work/slot_review/<인물>.txt`
- 검사 → `work/slot_review/_검사.tsv`, 빌드 실패 조건:
  - 대명사·호칭 칸 값의 받침 불일치(같은 칸에 받침 있는 값이 섞임)
  - 칸 뒤 받침 민감 조사(은/는 이/가 을/를 와/과 으로/로 이야/야)가 값 받침과 안 맞음(인물별)
  - 틀 위반: 12:01 앞 받침 없음 · 12:08 앞 받침 있음 · 12:02/12:04 앞이 «ㄹ/ㄴ 받침 + 띄어쓰기» 아님 · 12:07 앞 «않» 아님
  - 칸 값 빈칸으로 생기는 이중 공백·부호 앞 공백
  - 칸 값에 표 밖 글자(인코딩 불가)

## 5. 진행
1. cc_slot TSV 의 «(칸 이름)» 줄 KO 칸에 새 뜻 기입(디버그 표시용, 자동)
2. 하스피: cc_slot 66명 값 채움(2장 규칙) → 범용 대사 번역(3장 규칙)
3. slot_check → 화자별 읽기 파일 검토 → 빌드

## 6. 애칭 `{08:81}`/`{08:82}`
세르주 이름 앞 1·2글자(«セー様», «セル兄ちゃん»). 한국어 «세르 오빠»(앞 2글자 = «세르») 식으로 그대로 쓸 수 있음 — 이름 확정 후 결정
