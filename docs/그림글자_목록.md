## G04 전투 소형 글꼴 — 전수 조사·설계 (2026-11-16 2차 세션)

- 전투 코드 = 파일 6(=2538), 적재 0x800A9F00. 표 고르기 0x800C6818(a0 = 이름 번호×4, osak = 4), 그리기 0x800C6950(x, y, 번호)

### 실측 (임시 번역 work/g04/names_ko.tsv — 인물 45 · 적 149 · 라벨 32)
- 이름 음절 190 + 라벨 전용 40 = **230음절** (11자 초과 0, 파티 6자 초과 0)
- 한 겹으로 쓸 수 있는 한글 칸 ≈ 170(8×9 칸, 영숫자·부호 칸 빼고) → 모자람

### 설계
1. **2겹 아틀라스**: 색인 4비트 중 아래 2비트 = A층, 위 2비트 = B층. CLUT A = 원래 자리(448,240)를 [투명·그림자·흰·−]×4 로, CLUT B = 아틀라스 맨 아랫줄 오른쪽 64px(VRAM 1008,430)에 16색. 조각의 CLUT 필드로 층을 고름 → 코드 수정 0, 새 VRAM 0
   - 용량 ≈ 8줄×32칸×2겹 − 영숫자·부호 ≈ **420음절** (이름·라벨 230 + 이름 입력판 몫 ≈ 190)
2. **변환식 그대로**: 이름에 쓰는 음절을 대사 글꼴 2바이트 칸 맨 앞(0x14C~)에 몰아 배정 → osak 표를 257+K 개로 늘림(1바이트 한글 칸 80개는 11~90). 표·아틀라스는 빌더가 번역 TSV 에서 자동 생성, 이름에 표 밖 음절이 있으면 빌드 오류
3. **라벨**(공격·엘리먼트·상태이상·능력치)은 음절 칸을 이어 붙인 여러 조각 스프라이트로 → 따로 자리 안 먹음
4. 글리프 = 갈무리7 BDF 화소 그대로 7×7 + 원본과 같은 그림자(잉크 바로 아래 1px) — `tools/smallfont.py`, 견본 work/g04/preview_01/
